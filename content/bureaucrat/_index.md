Bureaucrats handle administrative tasks for the event. If you've been assigned this role, you're responsible for user management, answering questions, and keeping records organized.

## What Bureaucrats Do

The bureaucrat role sits between supporters and full administrators. You have access to user records and can handle tasks that individual supporters can't, like viewing information across all angel types or managing work logs.

Day-to-day bureaucrat work often involves processing user requests, updating records when angels arrive at the venue, answering questions submitted through the system, and maintaining the FAQ.

## Bureaucrat Capabilities

As a bureaucrat, you can:

- **Confirm angel types** across all teams (not just ones you support)
- **View and edit user profiles** including contact information and settings
- **Manage work logs** - add, edit, or remove manual hour entries
- **Edit goodie status** - track t-shirt pickups and similar items
- **Answer questions** submitted by angels through the system
- **Edit the FAQ** to help angels find information themselves
- **View logs** of system activity

What you typically can't do (these require higher admin access):

- Create or edit shifts
- Manage locations or angel types
- Post news announcements
- Change system configuration

The exact permissions vary by event - some events give bureaucrats more capabilities, others fewer.

## Getting Started

When you log in, check for pending questions from angels. These appear in the Questions section and often need timely responses. Also check if there are angels waiting for angel type confirmation.

Your main tools are the user administration area and the FAQ/Questions sections. Get familiar with these first - they're where you'll spend most of your time.
