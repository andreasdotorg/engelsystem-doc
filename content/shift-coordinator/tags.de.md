Tags helfen beim Organisieren und Filtern von Schichten, Orten und anderen Entitäten im System.

## Wofür Tags da sind

Tags bieten flexible Kategorisierung über feste Strukturen hinaus. Häufige Verwendungen:

- **Schichtkategorien** - "Schweres Heben", "Deutsch erforderlich", "Rollstuhlgerecht"
- **Fähigkeitsanforderungen** - Technische Expertise, Sprachkenntnisse
- **Zeiträume** - "Tag 1", "Nachtschicht", "Aufbau"
- **Besondere Bedingungen** - "Ruhiger Ort", "Draußen", "Hohes Aufkommen"

## Tags erstellen

Um einen neuen Tag zu erstellen:

1. Navigiere zur Tag-Verwaltung
2. Klicke Erstellen/Hinzufügen
3. Gib den Tag-Namen ein
4. Speichern

Halte Tag-Namen:
- Kurz und klar
- Einheitlich formatiert
- Beschreibend für das, was sie repräsentieren

## Tags verwenden

Einmal erstellt, können Tags angewendet werden auf:
- Schichten
- Orte
- Andere Entitäten je nach Konfiguration

Tags helfen Freiwilligen, relevante Möglichkeiten zu finden, und helfen Koordinatoren, den Zeitplan zu organisieren.

## Best Practices

- **Konsistent sein** - Den gleichen Tag für den gleichen Zweck durchgehend verwenden
- **Nicht über-taggen** - Zu viele Tags werden verwirrend
- **Bedeutungen dokumentieren** - Sicherstellen, dass Teammitglieder wissen, was jeder Tag bedeutet
- **Regelmäßig überprüfen** - Unbenutzte Tags entfernen, Duplikate zusammenführen
