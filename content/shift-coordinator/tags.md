Tags help organize and filter shifts, locations, and other entities in the system.

## Required Privilege

You need the `tag.edit` privilege to manage tags. This is included in the Shift Coordinator group.

## What Tags Are For

Tags provide flexible categorization beyond fixed structures. Common uses:

- **Shift categories** - "Heavy lifting", "German required", "Wheelchair accessible"
- **Skill requirements** - Technical expertise, language skills
- **Time periods** - "Day 1", "Night shift", "Setup"
- **Special conditions** - "Quiet location", "Outdoor", "High traffic"

## Creating Tags

To create a new tag:

1. Navigate to tag administration
2. Click create/add
3. Enter the tag name
4. Save

Keep tag names:
- Short and clear
- Consistently formatted
- Descriptive of what they represent

## Using Tags

Once created, tags can be applied to:
- Shifts
- Locations
- Other entities depending on configuration

Tags help volunteers find relevant opportunities and help coordinators organize the schedule.

## Best Practices

- **Be consistent** - Use the same tag for the same purpose throughout
- **Don't over-tag** - Too many tags becomes confusing
- **Document meanings** - Make sure team members know what each tag means
- **Review periodically** - Remove unused tags, consolidate duplicates
