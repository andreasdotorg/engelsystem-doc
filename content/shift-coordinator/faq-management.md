Shift Coordinators can create and edit FAQ entries to answer common questions before volunteers need to ask.

## Required Privilege

You need the `faq.edit` privilege to manage FAQ entries. This is included in the Shift Coordinator group.

## Accessing FAQ Management

Navigate to **FAQ** and click the edit or management option to access FAQ administration.

## Creating FAQ Entries

When creating a new FAQ entry:

1. **Question** - Write the question as a user would ask it
2. **Answer** - Provide a clear, complete answer
3. **Category** (if available) - Organize entries by topic

### Writing Effective FAQ Entries

- **Use natural questions** - "How do I get my t-shirt?" not "T-shirt distribution procedure"
- **Be concise** - Get to the answer quickly
- **Include specifics** - Locations, times, and contact info where relevant
- **Update regularly** - Remove outdated info, add new common questions

## Editing Existing Entries

To update an FAQ entry:

1. Navigate to the FAQ
2. Find the entry to edit
3. Click edit
4. Make your changes
5. Save

## Organizing the FAQ

Good FAQ organization helps volunteers find answers:

- **Group by topic** - Shifts, goodies, locations, etc.
- **Put common questions first** - Most-asked questions should be easy to find
- **Use clear language** - Avoid jargon and abbreviations

## When to Add FAQ Entries

Consider adding FAQ entries when:

- Multiple volunteers ask the same question
- Upcoming changes will generate questions
- Processes are commonly misunderstood
- You want to reduce question volume

{{% notice tip %}}
Review the Questions queue regularly. Repeated questions are good candidates for new FAQ entries.
{{% /notice %}}
