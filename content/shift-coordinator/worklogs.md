Work logs allow you to record volunteer work hours outside of the normal shift system. This is useful for tasks that don't fit into scheduled shifts.

## Required Privilege

You need the `admin_user_worklog` privilege to edit work logs. This is included in the Shift Coordinator group.

## When to Use Work Logs

Use work logs for:

- **Ad-hoc tasks** - Unscheduled work that wasn't part of a shift
- **Corrections** - When shift records don't accurately reflect hours worked
- **External work** - Contributions made outside the normal shift system
- **Pre-event work** - Setup and preparation before the event begins

{{% notice warning %}}
Work logs should supplement, not replace, the shift system. For regular scheduled work, use shifts.
{{% /notice %}}

## Creating a Work Log Entry

To add work hours for a volunteer:

1. Navigate to the user's profile
2. Find the work log section
3. Click add/create
4. Enter:
   - **Hours** - Amount of time worked
   - **Description** - What the work involved
   - **Date** (if applicable) - When the work was done
5. Save the entry

## Editing Work Logs

To modify an existing work log:

1. Navigate to the user's profile
2. Find the work log section
3. Click edit on the entry
4. Make changes
5. Save

## How Work Logs Affect Rewards

Work log hours count toward:

- **Total hours worked** - Included in the volunteer's hour count
- **Voucher eligibility** - Hours contribute to earning vouchers
- **Goodie eligibility** - Hours contribute to "active" status
- **Statistics** - Appear in event reports

## Best Practices

- **Be specific** - Write clear descriptions of what the work was
- **Be timely** - Add entries promptly while details are fresh
- **Be accurate** - Record actual hours worked, not estimates
- **Document context** - Note why a work log was needed instead of a shift

## Auditing Work Logs

Work log entries are visible in user profiles and contribute to overall statistics. If discrepancies are found, investigate before making changes.
