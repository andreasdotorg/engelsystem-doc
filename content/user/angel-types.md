# Understanding Angel Types

Angel types are categories of volunteer work defined by event organizers. Each type groups related shifts and can have its own access controls and requirements.

## How Angel Types Work

Angel types control which shifts you can sign up for. When you join an angel type, shifts of that type become available to you in the shift overview.

Angel types can be configured with different access levels:

- **Self-signup** - Anyone can join immediately
- **Requires approval** - A supporter must approve your membership
- **Hidden** - Only visible to users who are already members

## Viewing Angel Types

The Angel Types page shows all types available at your event. Each type displays:

- **Name and Description** - What the work involves
- **Member Count** - How many people have joined
- **Shift Count** - How many shifts exist for this type
- **Access Level** - Whether you can self-signup or need approval
- **Supporters** - Team leads who manage this type

## Joining an Angel Type

### Self-Signup Types

For types with self-signup enabled:

1. Go to the Angel Types page
2. Click "Join" on the type you want to join
3. You're immediately a member and can sign up for shifts

### Restricted Types

For types requiring approval:

1. Go to the Angel Types page
2. Click "Apply" on the type you want to join
3. Wait for a supporter to review and approve your application
4. Once approved, you can sign up for shifts of that type

{{% notice note %}}
Supporters may ask questions or check qualifications before approving your application to restricted types.
{{% /notice %}}

## Leaving an Angel Type

You can leave an angel type from the Angel Types page. This removes your membership but doesn't affect any shifts you've already signed up for.

## Angel Type Requirements

Some angel types may have additional requirements documented in their description:

- **Skills or Certifications** - Professional qualifications needed
- **Experience** - Prior work in related types
- **Training** - Attendance at introduction sessions

Check the type description carefully before applying.

## Contact Information

Each angel type can display contact information:

- **Supporters** - Team leads who can answer questions and approve applications
- **Contact Details** - Email or phone numbers for the team

If you have questions about a specific type, reach out to its supporters.
