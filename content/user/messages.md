Engelsystem includes a built-in messaging system for communication between volunteers.

## Accessing Messages

Navigate to **Messages** in the main menu to see your inbox and sent messages.

## Sending Messages

To send a message to another volunteer:

1. Go to their profile page (search in the user list or click their name anywhere in the system)
2. Click **Send message**
3. Write your message
4. Click **Send**

Alternatively, from the Messages page:

1. Click **New message**
2. Search for the recipient by name or nickname
3. Write and send your message

## Reading Messages

Your inbox shows:
- Sender name
- Message preview
- Date/time received
- Read/unread status

Click a message to read the full content and reply.

## Message Notifications

The system shows a notification indicator when you have unread messages. Check regularly, especially during the event.

{{% notice tip %}}
Use messages for coordination that doesn't need to be public. For announcements that should reach everyone, ask a coordinator to post news instead.
{{% /notice %}}
