# Creating Your Account

Before you can sign up for shifts, you need to create an account in the Engelsystem.

## Registration Methods

### Standard Registration

1. Go to your event's Engelsystem URL
2. Click "Register"
3. Fill in the required information:
   - **Username** - Your login name
   - **Email** - For notifications and password recovery
   - **Password** - Choose a strong password
4. Submit the registration

### OAuth Registration

If your event has configured OAuth providers (like GitHub, Google, or a custom SSO), you can register using those accounts. Click the provider button on the login page to authenticate.

{{% notice note %}}
Some events require registration approval before you can access the system. Check your email for confirmation.
{{% /notice %}}

## Profile Settings

After registration, complete your profile in the Settings section:

### Personal Information
- **Name** - Your real name (for identification)
- **Pronouns** - How you'd like to be addressed
- **Planned Arrival/Departure** - When you'll be at the event

### Contact Information
- **DECT Number** - Internal phone number (if the event uses DECT phones)
- **Mobile Phone** - Backup contact number

### Preferences
- **Language** - Interface language
- **Theme** - Visual appearance
- **T-Shirt Size** - For goodie distribution
- **Email Notifications** - Choose what notifications you receive

## Joining Angel Types

After registration, you can join angel types from the Angel Types page:

- **Self-signup types** - Join immediately by clicking "Join"
- **Restricted types** - Submit an application and wait for supporter approval

## Account Security

Use a unique password and don't share your credentials. Log out when using shared computers. If you suspect unauthorized access, contact the administrators.

## OAuth-Connected Accounts

If you registered via OAuth, you can manage your connected accounts in Settings. You can link additional OAuth providers or set a password for direct login.
